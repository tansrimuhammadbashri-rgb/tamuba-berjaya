# TAMUBA BERJAYA - Website Resmi Pengadaan Material Konstruksi

Website resmi B2B untuk **TAMUBA BERJAYA**, supplier dan pengadaan material konstruksi yang melayani kebutuhan proyek melalui komunikasi yang jelas, koordinasi pasokan, dan permintaan penawaran berdasarkan spesifikasi.

## Fitur Utama
- **Katalog Material Interaktif**: Fitur pencarian real-time, filter kategori, dan tombol tanya harga via WhatsApp dengan pesan otomatis ter-encode.
- **Formulir Permintaan Penawaran Proyek**: Formulir dinamis dengan kemampuan menambah/menghapus baris material, volume, satuan, dan lokasi proyek, menghasilkan ringkasan pesanan rapi untuk dikirim via WhatsApp atau Email.
- **Desain Industrial Corporate**: Tampilan profesional, elegan, responsif untuk HP dan desktop.
- **SEO Optimized**: Meta tags lengkap, Open Graph, sitemap.xml, dan robots.txt.
- **Zero Cost Hosting**: Siap deploy langsung ke GitHub Pages secara gratis.

---

## Panduan Deployment ke GitHub Pages (Gratis)
1. Buat akun [GitHub](https://github.com) jika belum memilikinya.
2. Buat **Repository baru** dengan nama `tamuba-berjaya` (Public).
3. Unggah (upload) seluruh file dari folder ini (`index.html`, `products.json`, `robots.txt`, `sitemap.xml`, `README.md`) ke repository tersebut.
4. Buka tab **Settings** di repository GitHub Anda.
5. Pilih menu **Pages** di sidebar kiri.
6. Pada bagian **Build and deployment**, pilih **Source**: `Deploy from a branch` dan pilih branch `main` (atau `master`) dengan folder `/ (root)`. Klik **Save**.
7. Tunggu beberapa menit hingga proses deployment selesai. URL publik Anda akan muncul di bagian atas halaman (contoh: `https://username.github.io/tamuba-berjaya/`).

## Panduan Google Search Console
1. Buka [Google Search Console](https://search.google.com/search-console).
2. Tambahkan properti baru dengan URL publik GitHub Pages Anda.
3. Verifikasi kepemilikan (metode HTML tag atau DNS jika menggunakan custom domain).
4. Masukkan tautan sitemap (`https://username.github.io/tamuba-berjaya/sitemap.xml`) pada menu **Sitemaps**.
5. Gunakan **URL Inspection** untuk meminta pengindeksan halaman utama.
